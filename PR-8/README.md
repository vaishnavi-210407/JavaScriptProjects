# 🛍️ Product Management & Cart System (JavaScript + LocalStorage)

A fully functional **Product Listing & Shopping Cart Web App** built using **HTML, CSS, Bootstrap, and Vanilla JavaScript**.
This project demonstrates core concepts like **CRUD operations, LocalStorage, dynamic UI rendering, and cart management**.

## 🚀 Features

### 📦 Product Management

* ➕ Add new product (name, image URL, price)
* ✏️ Edit existing product
* 🗑️ Delete product
* 🔍 Search products in real-time

### 🛒 Cart System

* Add product to cart
* Increase / Decrease quantity
* ❌ Auto remove item when quantity becomes 0
* 💰 Total price calculation

### 🎨 UI Features

* Responsive design using Bootstrap
* Modern card-based layout
* Clean and user-friendly interface

## 🧠 Concepts Used

* JavaScript DOM Manipulation
* LocalStorage (Data persistence)
* JSON (parse & stringify)
* CRUD Operations
* Event Handling
* Dynamic Rendering

## ⚙️ How It Works

1. Products are stored in **LocalStorage**
2. Cart items are also managed in **LocalStorage**
3. UI updates dynamically using JavaScript
4. Quantity logic:

   * Increase ➝ adds qty
   * Decrease ➝ removes item if qty = 0
